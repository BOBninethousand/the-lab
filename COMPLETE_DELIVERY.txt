================================================================================
                            WEBSOCKET HOOK
================================================================================

useWebSocket() Hook:
- Connects to ws:// or wss:// endpoint
- Auto-reconnects after 3 seconds on disconnect
- Filters out system events (ping/pong)
- Keeps last 50 events max
- Returns { events, isConnected }

Event Structure:
{
  type: 'task_started' | 'task_completed' | 'agent_update' | ...,
  message: 'Human readable message',
  timestamp: '2026-03-22T...',
  agent_id: 'agent-123'
}

                            DEPLOYMENT OPTIONS
================================================================================

OPTION 1: Static Host (Recommended)

→ Deploy dist/ to Vercel/Netlify/S3+CloudFront

COPY . .
RUN npm install && npm run build

FROM node:18
WORKDIR /app
RUN npm install -g serve
COPY --from=build /app/dist /app/dist
EXPOSE 3000
CMD ["serve", "-s", "dist", "-l", "3000"]
